# M2 任务与验收计划

目标：模型对话迁移至 Python FastAPI，Java 继续拥有全部业务数据和业务操作。

1. FastAPI基础：固定依赖、环境配置、健康检查及错误响应。
2. 委托鉴权：使用M1 AGENT_READ短期凭证，通过Java内部接口验证用户；不接收前端指定身份。
3. 会话与上下文：Python仅保存AI对话，按用户隔离；上下文有轮数与字符预算。
4. 模型适配：首先支持现有Ollama原生chat接口，隔离模型调用代码。
5. SSE生命周期：流式增量、完成/错误事件、总超时、取消、部分回答和并发保护。
6. 请求幂等：同请求ID可回放已完成结果；冲突及并发请求给出明确错误。
7. Vue接入：短期授权内存缓存、选择/恢复会话、新建会话、取消与错误展示。
8. Java清理：移除Spring AI及旧模型端点；保留M1业务与代理接口。
9. 验证：Python协议/鉴权/会话/上下文/异常测试，前端流协议测试与构建，Java M1回归。

验收：两个用户会话隔离；多轮历史进入服务端上下文；取消、超时、无效模型响应可恢复；
前端直接使用FastAPI对话；Java不再调用模型；没有引入Python订单、支付或库存实现。

范围：M2不实现RAG、工具调用、处方审核或AI下单。真实MySQL升级仍使用M1迁移说明。
