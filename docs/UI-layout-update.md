# UI 布局优化

日期：2026-10-27。保持白底、浅蓝主色和 Element Plus 控件，采用细分隔线与轻边框，
主要调整聊天页、应用导航和草稿核对页，未更改 Java/Python 接口与权限校验。

## 聊天空间

- 应用外壳使用100dvh与可收缩网格，聊天页占据导航之外的剩余高度。
- 聊天页拆为紧凑顶栏、独立滚动的消息区、底部输入区，替代原85vh加多层顶部堆叠。
- 操作说明移到“使用说明”；草稿未付款和需核对授权的提示仍可见。
- 选择清单仅保留底部一行摘要，详细商品、数量、阻断原因与授权按钮移至侧边抽屉。
  选择10种商品也不会把10行清单铺在对话上方。
- 已有待核对清单时，重复的商品查询结果默认折叠，仍可手动展开。
  商品查询没有清单时继续展开，保证查询结果可见。
- 向上阅读历史时暂停自动跟随，提供“回到最新消息”。
- Ctrl / ⌘ + Enter发送，Enter保留换行；输入区有最大高度和字数提示。
- 长文本、链接、商品名和来源文本可换行，消息区不会撑破横向布局。

## 导航和草稿页面

- 桌面使用紧凑侧栏，窄屏改为横向导航，当前路由正确高亮。
- 增加“我的草稿”导航，账号菜单保留个人中心和退出登录入口。
- 草稿列表与详情分区；金额、有效期、当前差异和收货表单有清晰层次。
- 草稿号、请求键、版本收进可展开的信息区，确认仍明确标注“不付款”。
- 清单勾选、数量绑定、阻断原因及独立授权调用使用既有逻辑；
  核对抽屉中的按钮才执行授权，不会因展开摘要自动授权。
- 移除遗留外部演示请求。Vue DevTools 浮动入口默认关闭，避免遮挡输入提示；
  开发时可通过环境变量 ENABLE_VUE_DEVTOOLS=true 显式启用。
- 页面标题和语言改为家庭健康助手与zh-CN。
