# M5.1-C 审查记录

审查范围：独立付款状态机、身份绑定、恢复标记、密码弹层、入口切换、响应拒绝、窄屏布局及规则库一致性。

| 审查项 | 结论 |
| --- | --- |
| 明确付款 | 验证不会调用pay；只有独立按钮触发；同一页面双击只发送一次 |
| UNKNOWN恢复 | 不自动换键、验证或付款；REGISTERED/登记缺失不推定未扣款 |
| 私密凭证 | 密码与授权原文不进入持久化、URL或AI；恢复存储明确白名单 |
| 切号及迟到 | 捕获原用户/会话/订单，迟到授权定向撤销；过时结果不改新页面 |
| 会话错误 | 支付密码失败不登出；旧请求401不能登出新账号 |
| 页面退出 | SPA销毁/pagehide清理；撤销尽力keepalive，父会话/有效期后端兜底 |
| 授权过期与验证锁定 | UI倒计时与Retry-After提示；后端继续做最终到期判断 |
| 环境一致性 | 启动器将同一受校验开关注入Java和Vite，正常环境仍关闭 |
| 旧入口 | 新模式下购物页和orderStore共同拦截旧直接成交路径 |
| 金额与状态 | 显示Java快照金额字符串与支付状态，不按余额或前端计算猜测成功 |

浏览器发现并修复：Element Plus弹窗关闭动画会在验证成功的程序关闭后再次发出false事件，原处理会撤销刚签发授权。
现在仅用户关闭仍打开的弹窗时执行撤回；真实浏览器已完成修复后明确付款，数据库核对只扣一次。
另修复了无效迟到授权撤销完成后的过时页面更新，补充存储访问异常与验证锁定处理，并约束草稿确认/取消的代次和会话检查。
窄屏品牌文字不再换行，七项长清单和验证弹层可达，没有横向溢出。

已覆盖协议模拟的超时、迟到响应、存储失败和明确回滚，同步记录真实浏览器与MySQL账务结果，两类证据没有混算。
