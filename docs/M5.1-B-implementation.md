## 已实现的流程

USER将本人CONFIRMED草稿转换为PENDING_PAYMENT订单，初始version=1，付款期限900秒。
Java复核草稿版本、原始转换期限、商品资格/审核版本、价格和库存，复制已确认收货及商品快照。
不预占库存、不扣款；source_draft_id唯一约束保证不同请求键也不会重复转换。
已有订单的重放可在草稿到期后读取该订单；历史NULL支付状态仅标记LEGACY_UNVERIFIED，不能接入新付款。

独立验证支付密码后签发32字节随机授权，base64url编码43字符，数据库只存SHA-256哈希。
授权绑定用户、父会话、订单、版本、金额和CNY，有效期不超过60秒、父会话或订单到期时间。
支付密码按原有BCrypt验证，UTF-8超过72字节拒绝；错误次数以独立事务提交，五次失败锁定900秒。
验证密码前不持有外层用户锁，避免独立事务互相等待。新授权撤销旧授权；定向撤销支持迟到响应清理。

付款必须使用USER身份、X-Payment-Authorization、Idempotency-Key及expectedVersion。
请求体禁止覆盖金额、用户、状态，版本不接受字符串、小数或布尔值，密码不接受数字隐式转换。
checkout/pay的请求指纹绑定操作、目标和版本；同键不同请求409。
请求先登记REGISTERED，再进入资金事务，明确拒绝后记录REJECTED，成功为SUCCEEDED。
已支付订单优先返回既有回执，重复使用已消费授权或更换请求键均不重复扣款。

## 事务与拒绝边界

统一锁顺序为用户→请求记录→草稿（checkout）→订单→支付授权→按商品ID升序商品。
所有资金写入在同一事务完成：余额、库存、积分、purchase流水、唯一支付记录、订单PAID/version+1、授权CONSUMED和请求SUCCEEDED。
数据库唯一约束约束来源草稿、支付订单、关联流水及请求键。积分按现有规则取金额整数部分，并检查int溢出。

取得全部锁后、首次资金变更前再次验证会话、订单和授权有效期；consumed_at记录此授权使用时刻。
paid_at记录付款写入时刻，事务提交延迟不会追溯否定已在有效期内取得的支付授权。
提交前再次验证父会话。过期、退出或跨会话授权不能用于新的资金操作。

确定的业务拒绝通过事务结果返回，先提交撤销/关单，再在事务外抛出业务错误，避免撤销被异常回滚。
价格或资格变化关闭订单为CATALOG_CHANGED；余额或库存不足保留待支付并作废相应授权，用户重新核对后再验证。
关闭与支付共用用户/订单锁，已付款不可关闭或物理删除。
可确认完成回滚的执行故障返回503 TRANSACTION_RETRYABLE/NOT_APPLIED；提交结果无法确认返回PAYMENT_OUTCOME_UNKNOWN/UNKNOWN。
客户端必须保留原请求键，通过GET本人订单及paymentRequestKey恢复；不得自动换键或再次扣款。

PaymentHooks.afterDebit为无操作的Java测试接缝，测试通过Spy注入故障证明扣款后回滚；没有HTTP故障开关。
AGENT_READ、AGENT_ORDER_PREPARE均无支付入口权限，Python/LLM只能读取所有权检查后的白名单摘要。

## 显式迁移、恢复与重现

在项目根目录执行，使用已配置且Git忽略的.env.local/.env.demo.local，不在命令行传密码：

```powershell
python scripts/demo.py stop
python scripts/m51_migrate.py
python scripts/m51_restore_drill.py
python scripts/demo.py start
python scripts/m51_live_smoke.py
python scripts/m51_mysql_tests.py
python scripts/validate_m51b_contract.py
python -m unittest discover -s scripts -p "test_*.py"
python -m compileall -q scripts
```

Java目录执行mvn test package。Maven默认执行65项、跳过18项需要显式临时MySQL环境的测试；专用脚本单独运行这18项。
MySQL脚本创建随机一次性库和仅对此库授权的临时账号，验证该账号无法访问正常库后运行测试，finally删除账号、库及私有配置。
迁移仅允许带环境标记的固定演示库，迁移前备份、拒绝服务运行中迁移。MySQL DDL隐式提交不能通过事务回滚。
脚本将15个DDL步骤逐项记账，断在DDL提交但未写步骤记录时可据元数据继续。本次已实际注入第二步后中断并成功续跑，随后重跑新增DDL为0。
不支持将未知人工修改的半迁移结构直接作为受信任生产迁移；漂移需先审核，禁止自动删除修复。
恢复演练将私有备份导入全新随机临时库并检查支付结构、环境标记与行数，绝不覆盖原业务库。
备份、凭证和原始日志保留在受ACL保护的.local-demo，公开证据仅保留脱敏结果。

旧M4全链路脚本含直接钱包成交断言，不适用于启用M5的演示栈；旧流程回归通过默认关闭模式Java测试覆盖。
模型/RAG与Vue源码保持M4.3版本，未将旧浏览器截图当作本阶段付款页面验收。
