## 浏览器实际检查

合成账号在13000界面输入资料并确认，随后进入付款、输错一次密码再正确验证；错误验证未退出有效登录。
确认资料和验证后，合成余额仍为50.00、库存100、购买流水0。
明确点击付款0.40后，余额49.60、库存96、积分0、购买流水与支付记录各1。
刷新回执、关闭另一笔待支付订单和撤回另一授权后，上述资金与库存不再变化，ACTIVE授权数为0。
另一账号访问旧订单显示记录不存在，不显示商品、收货资料或回执；返回原账号可读取已付款回执。
长时间测试中旧草稿按15分钟规则拒绝转换，未延长旧期限；用新合成草稿完成后续撤回检查。
