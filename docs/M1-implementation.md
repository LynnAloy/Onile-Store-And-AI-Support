# M1 实施与运行说明

后续状态：M2已将对话迁移至FastAPI，并移除Spring AI及旧/stream端点。
当前AI启动步骤见M2-implementation.md；本文件继续作为M1数据库升级说明。
以下变更清单记录M1交付时的范围。

本次范围：Java 认证及业务安全、现有 Vue 接入适配、Java/Python 只读契约。
保留 Java 技术栈。未创建 Python 服务；Spring AI 待 M2 替换。

## 代码变更

- BCrypt 12 轮保存登录密码和六位数字支付密码。
- 随机256位会话令牌、摘要存储、过期和服务端撤销；重新登录使旧会话失效。
- 登录与支付验证5次失败后锁定15分钟，失败记录独立事务持久化。
- 明文旧密码不自动回退验证，必须显式迁移。
- Spring Security 默认拒绝访问，只有注册、登录和必要静态资源公开。
- 用户资料、钱包、流水、订单查询和修改校验当前用户；关闭历史全量消息读取。
- 关闭普通用户直接改库存；资料修改采用白名单，拒绝未知JSON字段和小数数量。
- 钱包激活不能覆盖已有支付密码；充值卡单次使用；积分兑换拒绝零和负数。
- 下单必须校验服务端支付密码并提交 Idempotency-Key，同键不同内容返回409。
- 商品价格来自数据库；按固定顺序锁商品，账户、库存、订单、订单项、流水原子提交。
- 并发充值与并发下单采用数据库行锁；交易订单禁止物理删除。
- Vue 清除模拟API，修复开发代理，独立弹窗输入支付密码，并按服务端结果刷新状态。
- Python 只读代理接口同时校验服务身份与短期用户授权；详见接口契约。

## 现有 MySQL 升级

本次不自动执行任何现有数据库变更。先备份，确认使用现有 DeepSeekDoc 业务库。

1. 在数据库管理工具中，对目标库执行：
   src/main/resources/sql/migrations/V001_m1_security.sql
2. 该脚本扩展密码列、清除旧模拟token，并新增 auth_sessions、security_attempts、
   checkout_requests。脚本为手动迁移，不是自动 Flyway 任务。
3. 设置环境变量 DB_USERNAME、DB_PASSWORD，必要时设置 DB_URL。
   参照后端 .env.example；Spring 不会自动读取该文件。
4. 首次升级旧数据时，在受控本机环境设置 MIGRATE_LEGACY_PASSWORDS=true 后启动一次。
   Java 会把旧明文密码/有效六位支付密码改为 BCrypt，并撤销所有旧会话。
   不合规的旧支付密码会使钱包停用，用户需重新激活。
   旧登录密码超过72个UTF-8字节时，迁移会回滚，应先通过受控方式重置该账号密码。
5. 迁移成功后停止服务，清除 MIGRATE_LEGACY_PASSWORDS 或设为false，再正常启动。
   此开关只能用于一次性维护，不能持续启用，否则每次启动都会撤销会话。
6. 新注册密码8-64字符且不超过72个UTF-8字节；旧短密码迁移后允许登录，
   后续应补充密码更新/重置功能，推动旧账号升级。
7. 旧 SQL 导出文件包含历史账号和个人资料，本次保留原始文件；发布项目之前需脱敏。

生产配置不再包含数据库账号密码；MyBatis SQL参数日志默认关闭，避免打印密码摘要。
数据库账号应有最小必要权限。M1没有实现管理员改库存接口，现有库存写入口被禁止。

## 启动与检查

Java目录：mybatis-plus-demo/mybatis-plus-demo。要求 JDK21、Maven。
设置数据库环境变量并完成迁移后执行 mvn spring-boot:run。

前端目录：DeepseekDoc。执行 npm run dev，默认 http://localhost:3000。
/api 与暂留的 /stream 由 Vite 代理至 Java 8080，不再移除 /api 前缀。
生产部署需配置同源反向代理。内部 /internal 不应作为浏览器公开业务入口。

自动化检查：
- Java：mvn test -B -ntp
- 前端：npm run build
- 测试使用 H2 MySQL兼容模式，通过真实 HTTP控制器、鉴权过滤器、Mapper和事务验证业务。
  不访问本机 MySQL，不调用外部模型或支付服务。

## M1 边界

- 数据库迁移脚本与现有 MySQL 实例的部署检查需要实际环境执行，本次测试不等同于 MySQL 联调。
- 当前仍是用户确认支付密码后立即成交的钱包流程；完整草稿订单、支付状态机、
  处方审核、退款、第三方支付回调及真实资金接入在后续里程碑实现。
- 现有 Java 对话流保留并加入鉴权，M2再迁移至 Python；健康会话持久化隔离在M2完善。
- USER token 沿用前端 localStorage。公开部署前需结合XSS防护评估迁移到更严格的浏览器会话方案。
- 登录/支付的数据库失败限流已实现；网关级IP限流、注册防滥用与验证码不在本次实现范围。
