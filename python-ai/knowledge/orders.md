# 订单、价格与库存

用户在对话中明确购买商品和数量时，AI会先查询目录并生成只读的“待核对购买清单”，保留每种商品的请求数量。清单不是草稿、授权或成交订单。即使商品未审核，也可勾选、取消选择和调整数量，但不能绕过资格门禁准备草稿。未指定数量时需补充，多规格匹配时需先选定具体商品。

商品价格和库存来自Java实时商品数据库，知识库中的文字不能代替实时查询。AI可通过只读工具按商品名称查询目录、按商品ID查询详情、按订单号查询本人订单摘要。只有工具执行成功才能声称完成查询。查询卡片显示时间快照，不保证后续价格和库存不变。

用户可从商品卡片明确授权AI准备指定商品和数量的未付款草稿，授权最长五分钟且可撤销，健康档案授权不能替代此授权。草稿准备与确认均不扣款、不减库存，不代表正式订单成交。默认流程中 AI 不能自行确认、付款或修改库存。

只有销售资格审核通过、依据完整的非处方商品才能准备草稿；分类未知、待审核或处方商品目前会被拦截。商品搜索命中不表示适合某种症状，不能作为药物适用性推荐。

用户在独立的“我的草稿”页面核对商品与收货信息。确认前Java重新校验价格、库存与审核版本，调价或资格变化需重新准备草稿。草稿十五分钟内有效，过期不能确认。停止回答或网络中断不保证撤销已保存的草稿，可在本人草稿列表恢复查看。

启用独立付款的环境中，用户在“我的草稿”确认收货资料后，点击“进入独立付款”创建待支付订单，此操作不扣款。待支付订单十五分钟内有效，不预占库存。用户独立验证支付密码后，还需明确点击“确认付款”，才由Java原子完成付款。服务端以已核对的商品快照及实时资格、价格、库存校验为准，不接受模型或前端覆盖金额。

密码验证成功只签发最长六十秒的一次性授权，不等于付款。网络异常或付款结果不确定时，用户通过“付款订单”查询原订单；页面不会自动重新验证或再次扣款。只有Java返回PAID及付款回执，才可确认新流程已经付款；CONFIRMED仅代表草稿资料已确认。

独立付款环境中，服务重启后留下的登记请求超过一百二十秒时，后台会按与付款相同的锁顺序核实结果：已经付款的保留原回执，尚未结算的结束旧尝试并阻止迟到请求继续扣款。页面查询确认旧尝试未执行后，仍需用户重新验证并明确付款；后台不会代付或自动重试扣款。

未启用独立付款的环境保留原购药入口，新付款能力以页面环境提示为准。隔离演示不自动审核正常商品，不把演示审核视为真实药品资格。

同一个下单请求的幂等键只能对应同一份订单内容；重复提交不能重复扣款。库存、账户扣款、订单和流水在同一数据库事务中提交。库存不足或余额不足时不能成功成交。

订单查询只能查看当前登录用户的订单。启用独立付款时，待支付订单可由用户明确关闭，已付款订单不可关闭；历史未核验订单不能推定为新流程PAID。交易记录不可直接物理删除，退款和第三方支付对账仍属于后续阶段。模型不能签发支付授权或获取支付密码；自动扣款仅由下述钱包授权规则下的 Java 结算执行。


钱包开启“允许 AI 智能下单”后，本次登录中的新对话轮次可在已授权额度内自动购买审核通过的 OTC 商品并扣演示钱包。用户须明确完整商品名称和每种数量；模糊咨询、处方商品、未审核、多规格、缺数量或部分清单均不能自动成交。模型仍只产生只读购买清单，浏览器在该轮回答完成后调用 Java 受限结算；AGENT_READ 和订单准备凭证都不能调用资金接口。AI 清单中的“尚未下单”是生成时的快照，最终以 Java PAID 回执为准，模型不能预先宣称成交。

默认单笔 50 元、每日 200 元。每日额度按 PST 固定 UTC−08:00 自然日计算，不随夏令时变化。启用、重新启用或提高任一额度需验证支付密码；关闭和降低额度不需要密码。授权绑定当前登录，重新登录需重新验证开启；关闭、重新开启或重新登录不重置当天已用额度。自动下单从本人个人资料读取收货人、手机号和地址填单，资料不完整或在本轮中变化则拒绝；收货资料不发送给模型。健康资料个性化授权与钱包下单授权分别控制。

管理员可以调整库存并审核 OTC/RX 分类，必须填写可追溯依据，审核人和变更版本由服务器记录。修改分类不会自动通过审核。现有未审核商品不会被自动放行。自动结算复核最新库存、资格、价格和余额，以用户锁串行累计额度；同一轮次只成交一次。不确定结果只查询原轮次或付款订单，不能自动重试写入或更换轮次扣款。


P1风险门禁补充：开启钱包自动下单不等于通过健康风险复核。自动交易还需要用户授权健康资料、年龄18至64岁、完整且明确的无病史/无已知过敏/无当前用药自述，以及其他健康信息明确为“无其他健康风险”；应按真实情况填写，不能为了启用功能虚填。存在风险、信息不足或商品证据缺失/失效时，只生成清单并转人工核对，不自动扣款。这是演示自动化门禁，不是用药安全证明或药师审核。

管理员在药品管理的“审核证据”维护分类、成分、适用范围原文、来源与单次自动购买件数上限。类别检索仅返回有有效审核依据的匹配，输出证据来源和版本；点名查询库存不等于确认该商品属于医疗类别。模型推测不能代替审核事实。

扣款结果未知后，即使查询失败或登录过期，也不能声称未扣款；请恢复登录后查询原轮次或付款订单，不重复发送购买消息。
